# Amazing-Hand-Reforged
This project, Amazing Hand Reforged, is a redesigned version of the original Amazing Hand.

We sincerely acknowledge and thank the Pollen Robotics team for open-sourcing the Amazing Hand, which has enabled researchers, hobbyists, and DIY enthusiasts to access a low-cost dexterous hand platform.

That said, the original design does not strictly follow mechanical design standards, which leads to several practical issues in real-world fabrication and operation. These include tolerance inconsistencies across different manufacturing platforms, uncontrolled compliance at the fingertip, and non-standardized mechanical interfaces between components. As a result, there is a noticeable gap between the intended design and actual performance.

In this work, we revisit the design from an engineering perspective. A key benchmark in our design philosophy is whether the hand can reliably manipulate extremely fine objects (e.g., picking up a needle). Based on this goal, the entire model has been reworked, introducing thrust bearings and constraint pins where necessary to achieve a balanced trade-off between friction, stiffness, and mechanical robustness.

To better support DIY users, the entire model has been redesigned using SolidWorks 2020, a widely adopted industry-standard CAD tool.

This repository includes the single-finger source files, along with STEP and STL formats. If you are using SolidWorks 2020 or later, you can easily modify dimensions and refine the design to suit your needs.

Contributions, suggestions, and new ideas are highly welcome.
